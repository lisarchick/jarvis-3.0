## ✨ Три способности

JARVIS 3.0 — голосовой агент. Не «командная строка с микрофоном» и не чат-бот, а ассистент, который **сам решает**, что сделать для ответа: поискать в интернете, открыть программу, поставить таймер или честно сказать «не могу».

| | | |
|---|---|---|
| 🗣 **Поговори с ним** | Непрерывный диалог: сказал «Джарвис» — и говори. Помнит контекст, перебивается («стоп» — и он замолчит на полуслове), отвечает голосом. | «Джарвис… а в долларах?» |
| 🔎 **Спроси что угодно** | Сам ищет в интернете, читает страницы, сворачивает ответ в пару фраз и называет источник. Без догадок: не уверен — проверит или скажет прямо. | «Кто изобрёл радио?» → «Обычно называют Маркони… по данным Википедии» |
| 🖥 **Доверь ему desktop** | С твоего разрешения: программы и папки, музыка, таймеры, заметки под диктовку, взгляд на экран. Удаляет только в корзину и только после подтверждения. | «Открой калькулятор», «поставь таймер на 10 минут» |

Для больших задач (презентации, картинки, код) — подключаемые внешние модели: JARVIS честно скажет, что сам он голосовой ассистент, и предложит подключить модель в настройках.

## 🧠 Что умеет агент

| Возможность | Как работает |
|---|---|
| Непрерывный диалог | Wake word или клавиша → разговор открыт до «пока» или паузы. Follow-up вопросы без повторения «Джарвис». |
| Barge-in | Начал говорить во время ответа — JARVIS мгновенно замолкает и слушает. |
| Глубокий поиск | Многоисточниковый веб-поиск → чистка страниц до Markdown → ранжирование источников → кэш 10 минут. Источники — чипами в UI. |
| Голос | edge-tts (Светлана/Дмитрий) со стримингом по предложениям: говорит, не дожидаясь всего ответа. Распознавание — Google без ключа или Whisper. |
| Память | SQLite + лёгкий векторный индекс: факты, предпочтения, заметки. «Ты вчера говорил, что предпочитаешь Spotify» — работает. |
| Программы и окна | Индекс установленных программ (Пуск, реестр, UWP), нечёткий поиск по-русски («дискорд»), список окон, фокус, мягкое закрытие. |
| Музыка | Умный выбор плеера: один установлен — включит его; несколько — спросит; ни одного — YouTube в браузере, сразу с треком. |
| Таймеры и будильники | Несколько именованных, переживают перезапуск приложения, сигнал + голос. |
| Диктофон и заметки | «Запиши заметку» — запись + расшифровка в память. «Создай документ и запиши туда» — файл на диске, имя прочитает вслух. |
| Взгляд на экран | «Посмотри на экран» / «что за ошибка?» → снимок → vision-модель → диагноз. Снимок одноразовый, индикатор съёмки виден. |
| Файлы | Удаление только в корзину (SHFileOperation), только в пользовательских папках, всегда с подтверждением. Системные пути заблокированы кодом. |
| Мелочи | Громкость, медиа-клавиши, буфер обмена, блокировка экрана, «сверни всё». |
| Персонаж 2.5D | Анимированный риг с параллаксом: дышит, мигает, следит взглядом, эмоции повторяют состояния агента (думает / ищет / делает / растерян). |

## 🔒 Разрешения и безопасность

- **Ничего без согласия.** До первого разрешения JARVIS не сканирует даже список программ. Разрешения гранулярные и отзываемые: скан приложений, открытие/закрытие, файловые операции, микрофон, экран, буфер, внешние API.
- **Рискованное — всегда с подтверждением.** Удаление в корзину спрашивает каждый раз, даже при выданном разрешении.
- **Журнал действий.** Каждый вызов инструмента: время, аргументы, результат — в правой колонке UI.
- **Секреты не уходят.** Пароли и ключи детектируются кодом до отправки: в LLM, поиск и память они не попадают. Ключи API хранятся в DPAPI Windows.
- **Веб — это данные.** Текст страниц и скриншоты трактуется как данные, не как инструкции: команды из веб-контента не выполняются.

## 🤖 Модели

| Вариант | Что указать |
|---|---|
| Google Gemini | ключ Gemini, модель — по умолчанию flash-lite |
| Anthropic Claude | ключ Anthropic |
| OpenAI GPT | ключ OpenAI |
| Своя модель (OpenAI-совместимый API) | ключ + base URL + модель |
| Локальная (Ollama) | модель; base URL `http://localhost:11434/v1` |

Основная модель ведёт диалог и вызывает инструменты. Подключённые модели («эскалация») — с тегами возможностей `text / vision / presentation / image / code`: их JARVIS подключает для больших задач и «взгляда на экран».

## 📥 Установка (для пользователей)

1. Открой [Releases](../../releases/latest) и скачай `Jarvis_3.0.0_x64-setup.exe` (установщик) или `Jarvis-Portable-3.0.0.exe` (портативный, без установки).
2. Запусти. Если SmartScreen предупредит про неподписанный файл: **Подробнее → Выполнить в любом случае**.
3. Разреши микрофон: Windows может спросить при первом запуске (Параметры → Конфиденциальность → Микрофон).
4. В настройках («Настройки → Модели») вставь ключ любой модели — и говори.

Без ключа модели работают локальные команды: программы, громкость, таймеры, заметки.

## 🛠 Сборка из исходников

Нужны: [Rust 1.80+](https://rustup.rs), Node.js 20+, Windows 10/11.

```bash
git clone https://github.com/lisarchick/jarvis-3.0.git
cd jarvis-3.0
npm install
npm run tauri dev      # запуск в dev-режиме
npm run tauri build    # установщик NSIS + MSI в src-tauri/target/release/bundle
```

Тесты: `cargo test --manifest-path src-tauri/Cargo.toml` — утилиты, path-guards корзины, парсеры SSE всех провайдеров, агентский цикл с mock-LLM, память и поиск.

## 🗂 Структура проекта

| Путь | Что делает |
|---|---|
| `src-tauri/src/agent.rs` | Разговорный цикл: стриминг LLM → предложения → TTS, цикл инструментов |
| `src-tauri/src/llm.rs` | Провайдеры (OpenAI-совм./Anthropic/Gemini), SSE, tool-calling, vision |
| `src-tauri/src/tools.rs` | Реестр инструментов со схемами + исполнение с разрешениями |
| `src-tauri/src/os.rs` | WinAPI: громкость (IAudioEndpointVolume), медиа-клавиши, окна, корзина, клипборд |
| `src-tauri/src/appscan.rs` | Сканер установленных программ: Пуск, реестр, UWP, медиа-приложения |
| `src-tauri/src/search.rs` | Веб-поиск: DDG → чистка в Markdown → ранжирование → TTL-кэш |
| `src-tauri/src/tts.rs` / `stt.rs` | edge-tts (WSS, поток по предложениям) / Google + Whisper |
| `src-tauri/src/db.rs` | SQLite: чаты, факты с векторами, заметки, таймеры, журнал, индекс программ |
| `src-tauri/src/safety.rs` | Детект секретов, защита от prompt-инъекций, экран локальных моделей |
| `src-tauri/src/config.rs` / `secrets.rs` | Конфиг + DPAPI-шифрование ключей |
| `src/` | UI: React+TS, персонаж-canvas, чат, журнал, настройки, оверлей |

## ⚡ Против версии 1.0

| | v1 (Python) | v3 (Rust + Tauri) |
|---|---|---|
| Ядро | Python + PyInstaller (~200 МБ распаковка, медленный старт) | нативный Rust (~10–20 МБ, старт < 2 с, idle RAM < 150 МБ) |
| Команды | регексп-каскад, LLM — последний резерв | агентский tool-calling: LLM сам выбирает инструменты |
| Поиск | сниппет DDG + скрейпинг Google | многоисточниковый поиск с чтением страниц, ранжированием и кэшем |
| Память | факты, JSON-файл | SQLite + векторный поиск по смыслу |
| Голос | edge-tts по файлам | стриминг по предложениям, barge-in |
| Разрешения | нет | гранулярные, журнал действий, корзина-only |
| UI | CustomTkinter | frameless Dark Cyber-Clean, tray, оверлей по Alt+Space, 2.5D-персонаж |

## ⚠️ Отказ от ответственности

JARVIS управляет твоим компьютером в рамках выданных разрешений. Проверяй, что он удаляет (подтверждение — не формальность), и не давай доступ к компьютеру людям, которым не доверяешь. Проект не аффилирован с Microsoft; голоса edge-tts и веб-поиск — облачные сервисы соответствующих компаний.
