# JARVIS для iOS — сборка и установка

## Что внутри релиза

- `Jarvis-<версия>_iOS_Simulator.app.zip` — сборка для **симулятора** Xcode
  (не требует аккаунта Apple Developer). Распакуй и перетащи `.app` на открытый
  симулятор iPhone — приложение запустится.
- Для **реального iPhone** нужен Mac с Xcode и бесплатный Apple ID (личная
  подпись на 7 дней) или аккаунт разработчика ($99/год, TestFlight/App Store).

## Что работает на iOS

JARVIS на iPhone — голосовой ассистент-компаньон: два столпа из трёх.

| Возможность | Статус на iOS |
|---|---|
| Диалог с ИИ (Gemini/Claude/GPT/локальная) | работает |
| Веб-поиск с источниками и синтезом | работает |
| Память и заметки (SQLite + векторный поиск) | работает |
| Озвучка ответов | работает (системный TTS webview) |
| Распознавание речи | через микрофон webview |
| Таймеры/напоминания | локальные уведомления |
| **Управление компьютером** | **нет** — песочница iOS не даёт управлять
  другими приложениями, ставить глобальные хоткеи и трей (ограничение Apple) |
| Взгляд на экран | нет (приватность: нельзя снимать чужие приложения) |

Совет: держи JARVIS на ПК включённым — телефон может быть пультом, а агент на
компьютере выполнит desktop-часть (в планах — прямая связка, см. README).

## Сборка на своём Mac

```bash
git clone https://github.com/lisarchick/jarvis-3.0.git
cd jarvis-3.0
npm install
npx tauri ios init          # сгенерирует Xcode-проект (src-tauri/gen/apple)
npx tauri ios dev           # запуск на симуляторе
npx tauri ios build         # .ipa для устройства (нужна подпись)
```

Требования: macOS 13+, Xcode 15+, Rust (`rustup target add aarch64-apple-ios`),
Node 20+. В Xcode: Target → Signing & Capabilities → своя команда; при первом
запуске на устройстве: Настройки → Основные → VPN и управление устройством →
доверять сертификат разработчика.

## Заметки

- Разрешения Info.plist (микрофон, распознавание речи) уже прописаны в
  `tauri.conf.json` — Xcode спросит их при первом использовании.
- Версия Rust-ядра одна и та же на Windows и iOS; вся Windows-специфика
  изолирована за `cfg(windows)` / desktop-гейтами.
